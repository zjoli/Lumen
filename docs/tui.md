# TUI 界面与交互

## 布局

采用已确认的分栏工作台布局：外围和区域边界使用统一的单线框，顶部显示应用版本、工作区和会话；左侧为知识目录，右侧为内容区，右下方保留输入区。内容栏通过“会话 / 阅读”标识当前视图，F1、F2 分别切换到会话和阅读。底部单行状态栏集中显示运行状态、当前操作提示与模型。

知识目录作为左侧栏常驻显示，切换会话、阅读或输入焦点均不会关闭；独立会话未打开工作区时也保留目录栏，显示工作区提示。宽屏目录约占 23% 宽度（24–34 列），窄屏压缩目录宽度，为右侧内容和输入保留空间。目录数量置于标题旁，阅读区显示文档路径。输入区默认占 4 行，换行、引用和长草稿按需增高，小窗口进一步压缩以保留编辑光标；不嵌套额外编辑框。

供应商、模型和会话选择器共用单层边框与一致的搜索栏、选中行和底部提示。名称和状态分列，会话列表按标题与模型/时间分两行显示，不展示内部枚举调试名称。表单根据字段数量控制高度，较小窗口滚动到当前字段，API Key 始终遮蔽。打开弹窗时收起主界面的重复快捷键提示。

知识树依据 `member_of` 关系组织，支持领域、多级主题与六类知识对象。同一对象可出现在多个归属路径，打开时保持当前路径。目录不会在移动选择时自动替换正文，Enter 才打开。Ctrl+B 聚焦目录并刷新外部导入的知识；F6 或 Shift+Tab 可在目录、内容和输入区之间切换。

## 内容切换

- `/open <标题或 ID>` 或目录 Enter：打开 Markdown。
- `/chat`：显示本会话的消息流。
- `/read`：返回上次阅读的文档和位置。
- `/new`：新建会话并显示对话。
- `/help`、`/status` 等业务命令的结果显示在会话区域。

阅读时发送普通问题不会替换文档；新回复通过面板标题与状态栏提示，执行 `/chat` 查看。已在会话视图时实时显示流式回复。将鼠标置于对话区滚动，或使用 PgUp/PgDn 翻页；输入区仍保留草稿和编辑焦点。向上翻阅会暂停自动跟随，新的回复继续生成但不改变阅读位置。离开底部时，内容区右下角显示可点击的“↓ 回到最新”，点击或按 Ctrl+End 恢复跟随；内容区聚焦时 End 也可返回底部。输入草稿在区域、视图和主题切换时保留。

## 输入与光标

输入区默认获得焦点。使用终端原生、不闪烁的方块光标，光标位置按 UTF-8 字节边界、组合字符和实际显示列宽计算，兼顾中文和输入法定位。Enter 发送，Ctrl+J 换行；方向键、Home、End、Backspace、Delete 编辑。多行及长行支持视觉行移动和自动滚动，粘贴内容不会自动发送。

输入 `/` 即显示命令候选，继续输入前缀可筛选；粘贴命令前缀也会显示候选。目录、会话、阅读和查找区按 `/` 均进入命令输入，完整输入 `/quit` 后按一次 Enter 即保存会话并退出；`/exit` 也可退出。浏览目录或阅读正文时按 `f` 进入局部查找，Enter 确认、Esc 清除查找并返回。F1 切到会话并聚焦输入；点击输入区也可恢复编辑焦点。候选列表显示在输入区上方，小窗口至少保留一行候选。

使用 ↑↓ 选择候选，Enter 补全并直接执行选中的命令，无需再按一次 Enter；缺少必填参数时保留在输入框，补齐参数后再执行。Tab 只补全命令，方便继续编辑。`@` 知识引用的 Enter/Tab 只确认引用，不发送问题。列表可上下滚动选择，选中行显示 `›`。在命令中间确认时保留后面的参数。

有候选时 Esc 先收起列表，继续保留输入焦点；无候选时 Esc 转入内容浏览，i 返回输入。F6、Shift+Tab 分别顺序、反向切换区域；浏览按键不会在输入模式触发。

阅读时 a 引用当前章节；v 开始行选区，↑↓ 扩展后 a 引用。Ctrl+R 移除引用。发送时重新读取资料，旧选区所属文档若已经变化则要求重新选择。打开文档不自动发送全文。模型失败或取消时保留已有回复及草稿，不覆盖用户正在编辑的新草稿。

## 复制会话文字

`/copy`（或 `/copy last`）复制最近一条非空模型回复；`/copy all` 复制当前已加载的全部消息并附上发言者。复制使用消息原文，保留 Markdown、代码缩进和换行，不包含界面边框、目录栏或排版时产生的折行。输入草稿不会进入复制内容。回复生成过程中复制的是当时已收到的内容。

`/copy all` 的范围是当前界面已加载的消息，不会自动加载整个历史会话。需要更早内容时，先向上滚动加载历史，再复制。空会话或尚无模型回复时显示提示，保留命令输入。

复制通过 OSC 52 请求宿主终端写入剪贴板，也适用于支持该协议的远程终端；终端不提供写入成功回执，因此状态栏显示“已请求终端复制”。VS Code 从 1.91 起支持该协议；其他终端可能需要允许剪贴板写入。tmux 使用透传序列，需启用相应的 passthrough 支持。相关说明见 [VS Code OSC 52 支持](https://code.visualstudio.com/updates/v1_91#_support-for-copy-and-paste-escape-sequence-osc-52)。

局部选字可使用宿主终端的原生选择。TUI 开启鼠标捕获来支持滚轮和“回到最新”，普通拖拽会被转发给 TUI；在 VS Code 的 Windows/Linux 终端中，按住 **Alt** 再拖拽可强制终端选字，之后使用终端右键菜单中的“复制”。macOS 需先启用 `terminal.integrated.macOptionClickForcesSelection`，再按住 **Option** 拖拽。其他终端的强制选择修饰键由宿主决定。Ctrl+C 在 Lumen 中用于停止任务或清空输入；如果复制快捷键也被透传，使用宿主的复制菜单。参见 [VS Code 鼠标事件说明](https://code.visualstudio.com/docs/terminal/basics#_mouse-events-mode)。

## 终端主题与字体

默认 `auto` 直接使用当前终端的默认前景与背景，不指定固定 RGB 底色。强调、链接和错误使用终端的 ANSI 调色板；选中项交换终端的前景与背景，辅助文字和边线使用 DIM。消息、代码、输入区与弹窗均沿用终端底色，依靠边框和文字层级区分。程序不设置终端调色板，也不按操作系统的浅色/深色设置猜测终端颜色。切换 VS Code 等宿主的终端主题时，默认色和 ANSI 色由宿主更新。

若之前显式选择过固定主题，使用 `/theme auto` 恢复跟随；启动时可通过 `--theme auto` 覆盖 `LUMEN_THEME`。`/theme light`、`/theme dark` 仍作为手动覆盖保留，它们使用固定配色。生图预览中的深色背景与灰色块用于展示分区，自动主题以用户实际终端配色为准。

字体和字号由宿主终端控制，程序不设置字号、不使用放大标题或巨幅字符 Logo。VS Code 可设置 `terminal.integrated.fontSize: 13`，也可按个人习惯调整；建议使用包含中文的等宽字体回退。

## VS Code 快捷键透传

TUI 只能处理宿主终端转发的按键。VS Code 先处理快捷键，被其截获的 F1、Ctrl+B 等按键无法由 TUI 强行接管。项目的 [.vscode/settings.json](../.vscode/settings.json) 已配置终端优先：

```json
{
  "terminal.integrated.sendKeybindingsToShell": true,
  "terminal.integrated.allowChords": false,
  "terminal.integrated.allowMnemonics": false
}
```

在 VS Code 中打开本项目并将焦点放到集成终端后，大部分快捷键会转发给终端，包括运行中的 Lumen；连续组合快捷键和 Alt 菜单助记键也不再优先交给 VS Code。终端聚焦时，Ctrl+F 等原本打开 VS Code 面板的快捷键也会改为转发；焦点回到编辑器后，编辑器快捷键照常使用。配置影响本窗口的集成终端，不只影响 Lumen。

如果在其他 VS Code 工作区运行测试目录的二进制，请将这些设置加入那个工作区的 `.vscode/settings.json`，或通过 `Preferences: Open User Settings (JSON)` 加入用户设置。这属于宿主设置，无需重新构建二进制；操作系统或浏览器保留的按键仍需在相应宿主中处理。设置说明见 [VS Code 官方终端文档](https://code.visualstudio.com/docs/terminal/advanced#_keyboard-shortcuts-and-the-shell)。

## 运行与验证

`cargo run --bin lumen-tui -- --workspace /path/to/knowledge` 打开已有工作区。无工作区时可通过输入框执行 `/workspace init <路径>` 或 `/workspace open <路径>`。模型连接与别名配置见 [供应商配置](providers.md)，旧环境变量入口继续兼容；演示模型使用 mock。

全屏界面将渲染、输入与后台工作分离，退出前取消任务并关闭工作区、完成会话归档。全屏模式启用鼠标事件以支持滚动和点击，目录与内容区分别响应滚轮，弹窗阻止后台区域误操作；正常退出、错误返回和 panic 均恢复终端及鼠标模式。管道和 `--plain` 保留原有行模式。

自动化测试覆盖布局与主题、空输入及中文光标位置、换行与长草稿滚动、知识多归属及分页、Markdown 渲染、视图和草稿保留、流式回复、取消、引用新鲜度及会话持久化。伪终端验证另覆盖实际按键、光标显示、主题切换、窗口缩放和退出恢复；实际字体外观以 VS Code 的终端设置为准。

## 上下文窗口与 Skill

`/context` 查看最近已发送窗口的分区估算、输入预算、输出/工具预留和活跃指导。报告采用保守估算；新收到但尚未发送的输入会在下一次请求准备时计入。

`/compact` 安排下一请求前压缩；原始会话记录保留。`/skills` 列出用户、工作区和额外目录中的 Skill 及发现诊断。模型可以按需加载正文、读取资源、记录步骤并标记完成；活跃工作流在压缩后恢复。

`/sessions [query]` 打开会话列表，支持标题与正文搜索、归档标记、输入过滤和键盘选择；PgDn 请求下一页。`/resume <session-id>` 恢复会话，ID 可从列表或 `/context` 获取。聊天滚动到顶部时，继续向上滚动或按 PgUp 会异步加载更早记录，生成回复时也可读取。历史页合并后保持当前阅读位置，重复滚轮事件不会重复发起同一页读取；加载失败可继续向上滚动重试。切换会话后丢弃旧会话的迟到结果。UI 分页不会扩大模型上下文。

`/new [title]` 创建并选中新会话；`/session rename <title>`、`/session archive [id]`、`/session unarchive <id>` 管理元数据；`/session close` 释放当前会话。运行中切换被拒绝，先 `/stop` 并等待保存结束。不同会话分别保存草稿、阅读位置与引用；原文 revision 改变时清除旧选区。

独立模式使用 `LUMEN_SESSION_DIR` 或平台应用数据目录，启动恢复最近会话。旧单文件通过 `/session preview <path>` 浏览、`/session import <path>` 导入，原件保留；`/session inspect <id>` 可只读查看归档或存在恢复诊断的会话。

模型窗口容量、最大输出、协议格式及 Skill 目录配置见 [README](../README.md)。

## 供应商与模型配置

`/login` 打开可搜索的供应商目录，↑↓ 选择、Enter 打开配置；`/login <ID>` 直接进入。预设和已配置的自定义供应商使用同一套表单，新建自定义服务可选择 Chat Completions、Responses 或 Anthropic Messages 协议。认证方式可选 API Key、环境变量、无认证。Key 隐藏显示，支持粘贴；Tab/↑↓ 切换字段，最后一项 Enter 或 Ctrl+Enter 保存，Esc 取消。保存认证不发送网络请求。

`/model` 搜索已配置及已缓存的模型，Enter 直接切换已注册模型；也可选择供应商刷新远端列表。首次选择未注册的模型时需确认容量、别名和工具能力。缺失容量需要手工填写；模型规格不按名称猜测。`/models <供应商>` 也可刷新列表，`/logout [名称]` 移除本机 Key。

`/provider add` 是目录入口的兼容命令；`/provider add <名称> <Base URL>` 直接打开自定义表单，`/provider key <名称>` 修改 Key。无参数 `/models` 和 `/providers` 查看本机配置。表单和 Key 不进入聊天、会话草稿；范围、凭据保存方式与行模式命令详见 [供应商配置](providers.md)。

## 学习与研究命令

`/goal` 管理学习目标，`/plan show`、`/plan generate`、`/plan add`、`/plan move`、`/plan remove` 管理路线。`/progress` 查看完成情况和下一步，`/study` 开始导师对话，`/answer` 提交评估，`/review` 保存复盘；手工路线和完成记录可离线使用。具体参数见 [学习使用说明](study.md)。

`/web`、`/research`、`/fetch`、`/import` 用于联网资料检索、阅读和入库；`/services [reload]` 检查或重新接入外部服务，`/summary` 生成知识摘要。需要的接口和环境变量见 [外部服务说明](services.md)。这些命令均支持行模式，批量行模式有命令失败时返回非零退出码。

`/models` 查看模型别名、实际 ID 和容量，`/providers` 查看连接与协议；这两个命令运行中也可使用，不要求读取密钥。`/model <alias>` 在空闲时切换模型，缺少凭据只影响发送；配置错误不会自动转入演示模型。输出达到上限、拒绝和取消显示不同提示，未完成的工具参数不会执行。
