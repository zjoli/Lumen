# TUI 界面与交互

## 布局

布局采用左侧目录、右上内容、右下输入三个面板。顶部和底部各一行，显示工作区、模型连接状态与快捷键。区域共用连续的细线边界；标题置于面板内部的独立栏位，与正文对齐，焦点通过蓝色短标记提示。蓝色用于导航与选中行，紫色用于 Agent 和 Markdown 标记，字号保持统一。

宽屏目录约占四分之一宽度（28–40 列），较窄时为 24 列；窗口不足时自动收起，F1 打开、Ctrl+B 切换可见性。极窄窗口中，目录临时占据内容区，输入仍固定在底部。目录底部显示真实知识数量与操作提示，阅读标题栏显示知识路径。输入面板通常为 8 行，编辑框默认两行，引用和长草稿按需增高；输入滚动时原生光标始终保持在可视范围内。

知识树依据 `member_of` 关系组织，支持领域、多级主题与六类知识对象。同一对象可出现在多个归属路径，打开时保持当前路径。目录不会在移动选择时自动替换正文，Enter 才打开。F1 也可刷新外部导入的知识。

## 内容切换

- `/open <标题或 ID>` 或目录 Enter：打开 Markdown。
- `/chat`：显示本会话的消息流。
- `/read`：返回上次阅读的文档和位置。
- `/new`：新建会话并显示对话。
- `/help`、`/status` 等业务命令的结果显示在会话区域。

阅读时发送普通问题不会替换文档；新回复通过面板标题与状态栏提示，执行 `/chat` 查看。已在会话视图时实时显示流式回复；向上翻阅历史会暂停追尾，到达底部后恢复。输入草稿在区域、视图和主题切换时保留。

## 输入与光标

输入区默认获得焦点。使用终端原生竖线光标，光标位置按 UTF-8 字节边界、组合字符和实际显示列宽计算，兼顾中文和输入法定位。Enter 发送，Ctrl+J 换行；方向键、Home、End、Backspace、Delete 编辑。多行及长行支持视觉行移动和自动滚动，粘贴内容不会自动发送。

Esc 转入内容浏览，i 返回输入。F6、Shift+Tab 分别顺序、反向切换区域；浏览按键不会在输入模式触发。`/` 和 `@` 候选使用 ↑↓ 选择、Tab 确认。

阅读时 a 引用当前章节；v 开始行选区，↑↓ 扩展后 a 引用。Ctrl+R 移除引用。发送时重新读取资料，旧选区所属文档若已经变化则要求重新选择。打开文档不自动发送全文。模型失败或取消时保留已有回复及草稿，不覆盖用户正在编辑的新草稿。

## 终端主题与字体

`auto` 使用默认前景、默认背景和 ANSI 调色板，选中行使用 ANSI 蓝色背景；不主动改变宿主的终端调色板。边线使用较淡的终端颜色，正文和辅助文字保留默认对比度。VS Code 切换终端主题时，由终端重新映射这些颜色。

手动覆盖可选 `/theme light` 或 `/theme dark`：浅色采用近白底、淡蓝选中行和蓝紫强调色，与评审设计图一致；深色采用对应的深灰蓝层次。用 `/theme auto` 恢复继承。启动参数 `--theme` 优先于 `LUMEN_THEME`。`NO_COLOR` 由终端后端处理。

字体和字号由宿主终端控制，程序不设置字号、不使用放大标题或巨幅字符 Logo。VS Code 可设置 `terminal.integrated.fontSize: 13`，也可按个人习惯调整；建议使用包含中文的等宽字体回退。

## 运行与验证

`cargo run --bin lumen-tui -- --workspace /path/to/knowledge` 打开已有工作区。无工作区时可通过输入框执行 `/workspace init <路径>` 或 `/workspace open <路径>`。模型配置沿用 README 中的环境变量；未配置时明确标记演示模式。

全屏界面将渲染、输入与后台工作分离，退出前取消任务并关闭工作区、完成会话归档。正常退出、错误返回和 panic 均恢复终端。管道和 `--plain` 保留原有行模式。

自动化测试覆盖布局与主题、空输入及中文光标位置、换行与长草稿滚动、知识多归属及分页、Markdown 渲染、视图和草稿保留、流式回复、取消、引用新鲜度及会话持久化。伪终端验证另覆盖实际按键、光标显示、主题切换、窗口缩放和退出恢复；实际字体外观以 VS Code 的终端设置为准。

## 上下文窗口与 Skill

`/context` 查看最近已发送窗口的分区估算、输入预算、输出/工具预留和活跃指导。报告采用保守估算；新收到但尚未发送的输入会在下一次请求准备时计入。

`/compact` 安排下一请求前压缩；原始会话记录保留。`/skills` 列出用户、工作区和额外目录中的 Skill 及发现诊断。模型可以按需加载正文、读取资源、记录步骤并标记完成；活跃工作流在压缩后恢复。

`/sessions [query]` 打开会话列表，支持标题与正文搜索、归档标记、输入过滤和键盘选择；PgDn 请求下一页。`/resume <session-id>` 恢复会话，ID 可从列表或 `/context` 获取。聊天滚动到顶部后 PgUp 加载更早记录；UI 分页不会扩大模型上下文。

`/new [title]` 创建并选中新会话；`/session rename <title>`、`/session archive [id]`、`/session unarchive <id>` 管理元数据；`/session close` 释放当前会话。运行中切换被拒绝，先 `/stop` 并等待保存结束。不同会话分别保存草稿、阅读位置与引用；原文 revision 改变时清除旧选区。

独立模式使用 `LUMEN_SESSION_DIR` 或平台应用数据目录，启动恢复最近会话。旧单文件通过 `/session preview <path>` 浏览、`/session import <path>` 导入，原件保留；`/session inspect <id>` 可只读查看归档或存在恢复诊断的会话。

模型窗口容量、最大输出、协议格式及 Skill 目录配置见 [README](../README.md)。
